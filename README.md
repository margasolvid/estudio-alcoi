# Estudio · Administrativo Alcoi

App de estudio para la oposición de Administrativo del Ayuntamiento de Alcoi: 9 leyes marcadas (CE, EACV, LBRL, Ley 8/2010 CV, TRLRHL, LPRL, LO 3/2007, Ley 39/2015 y Ley 40/2015), banco de preguntas de exámenes, simulacros y ranking de artículos más preguntados.

Ábrela en el navegador desde el enlace de GitHub Pages. El progreso de cada persona se guarda en su propio navegador.
